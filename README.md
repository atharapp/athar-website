# موقع Athar (جامع كتب الأثر)

صفحة تعريفية لتطبيق **جامع كتب الأثر** — حمّل التطبيق، وتعرف على مميزاته، وجرّب نسخة الويب (PWA)، وتواصل معنا.

## روابط المشروع

- **الموقع الرسمي ومستودع الإصدارات**: [atharapp/athar-website](https://github.com/atharapp/athar-website) (يحوي كود الموقع وملفات الإصدارات والمشكلات).
- **نسخة الويب (PWA)**: [athar-online.vercel.app](https://athar-online.vercel.app/) — لتشغيل التطبيق مباشرة عبر المتصفح وتثبيته على الهواتف والأجهزة الذكية.
- **سجل الإصدارات والتنزيلات**: [صفحة الإصدارات على GitHub](https://github.com/atharapp/athar-website/releases).
- **الإبلاغ عن المشكلات والاقتراحات**: [GitHub Issues](https://github.com/atharapp/athar-website/issues).

## هذا الموقع

- موقع ثابت وسريع خفيف الوزن مبني بأحدث معايير تصميم Shadcn UI بنظام ألوان OKLCH.
- لا يحتاج إلى أي خطوات بناء معقدة: ملفات HTML و CSS و JavaScript نقية.
- يعرض أحدث إصدارات التطبيق تلقائياً عبر GitHub Releases API مع دعم الأنظمة الثلاثة: Windows و macOS و Linux.

## تطوير الموقع محلياً

```bash
python3 -m http.server 8080   # معاينة محلية
```
