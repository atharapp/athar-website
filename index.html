        الأسئلة المتكررة

        إجابات عن أهم الاستفسارات

        كل ما تحتاج لمعرفته حول تطبيق جامع كتب الأثر ومصادره ومميزاته التقنية.

        نعم، جامع كتب الأثر مشروع غير ربحي ومجاني 100% ومستقل لخدمة الباحثين وطلاب العلم في السنة والآثار. لا يحتوي على أي إعلانات أو تتبع أو اشتراكات مدفوعة.
        كلا، صُمم البرنامج بمبدأ (Offline-First)؛ فجميع الكتب وقواعد بيانات الرواة وفهارس البحث تعمل محلياً داخل جهازك عبر محرك SQLite مضمن فائق السرعة، ولا يتطلب أي اتصال بالشبكة بعد تنزيل الكتب.
        تتيح نسخة الويب عبر الرابط athar-online.vercel.app استخدام التطبيق مباشرة من أي متصفح مع إمكانية تثبيته كتطبيق تقدمي (PWA) على الهواتف والأجهزة اللوحية وحواسيب كروم بوك بنفس محرك البحث المحلي السريع.
        يضم التطبيق أمهات كتب السنة والآثار كـ: مصنف ابن أبي شيبة، مصنف عبد الرزاق، السنن للبيهقي، وجوامع ومسانيد الحديث، بالإضافة إلى قاعدة تراجم كبرى مستخرجة ومفهرسة من تهذيب الكمال وتقريب التهذيب مع الربط الشجري الدقيق.
        يمكنك الإبلاغ مباشرة عبر الضغط على أيقونة العلم بجانب أي أثر داخل البرنامج لفتح بلاغ مجهز مسبقاً، أو زيارة صفحة Issues على مستودع GitHub (atharapp/athar-website) وكتابة ملاحظتك واقتراحك.
        يقوم التطبيق بالتحقق التلقائي من التحديثات، كما يمكنك دائماً تحميل أحدث نسخة مستقرة عبر هذا الموقع الرسمي أو من صفحة Releases على مستودع GitHub (atharapp/athar-website/releases).
